# P1 y P4 (programacion lineal). OJO con la version: PuLP 4 es una reescritura
# que NO incluye ningun solver, asi que `pip install pulp` solo deja
# `listSolvers(onlyAvailable=True) == []` y el modelo falla con
# "HiGHS: Not Available: No module named 'highspy'". PuLP 3 trae el binario de
# CBC adentro y funciona sin instalar nada mas. Por eso el tope en <4: es la
# unica version que corre con un solo paquete.
#
# Si se quiere PuLP 4, agregar el backend:  pulp>=4 + highspy
# El codigo de comun/exacto/programacion_lineal.py detecta la version y usa la
# API disponible, asi que sirven las dos.
